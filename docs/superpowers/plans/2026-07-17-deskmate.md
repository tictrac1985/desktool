# DeskMate Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Windows desktop widget (clock/date + 9 quick tools), AR/EN, portable `DeskMate.exe` + installer `DeskMateSetup.exe`.

**Architecture:** Code-only WPF on .NET Framework 4.8, compiled directly with VS BuildTools Roslyn csc against GAC assemblies. One widget window pinned to desktop bottom z-order; shared popup panel window per feature; pure-logic units tested by a console SelfTest run inside the build script. Installer is a second WinForms exe embedding the app.

**Tech Stack:** C# (LangVersion latest on net48), WPF (WindowsBase/PresentationCore/PresentationFramework/System.Xaml), WinForms (NotifyIcon, installer UI), System.Drawing (icon gen), P/Invoke.

## Global Constraints

- Build must work with ONLY: `C:\Program Files (x86)\Microsoft Visual Studio\2022\BuildTools\MSBuild\Current\Bin\Roslyn\csc.exe` + assemblies under `C:\Windows\Microsoft.NET\Framework64\v4.0.30319` (+ `\WPF`). No NuGet, no SDK.
- csc flags: `/nologo /codepage:65001 /langversion:latest /target:winexe /platform:anycpu /optimize+ /win32icon:assets\app.ico`.
- Avoid net48-unsupported runtime features: no records/init-only (unless shim), no default interface members, no Span/Index/Range, no System.Text.Json. Tuples OK (4.8 has ValueTuple).
- All user-visible strings via `L.T(key)`; Arabic is default language; `FlowDirection` RTL when Arabic.
- Settings path: `%AppData%\DeskMate\settings.json` (MiniJson). Log: `%AppData%\DeskMate\log.txt`.
- Widget must never appear in taskbar/Alt-Tab (`WS_EX_TOOLWINDOW`), never above other apps; panels may be Topmost while open.
- Product name `DeskMate`, version `1.0.0`, publisher `DeskMate`.

- [ ] Calculator panel: display + simple grid; "Pro" toggle adds function keys; keyboard input.
- [ ] Wallpaper panel: OpenFileDialog (jpg/jpeg/png/bmp), style combo (fill/fit/stretch/tile/center → registry WallpaperStyle/TileWallpaper), apply via SPI_SETDESKWALLPAPER.
- [ ] Power panel: AC & DC rows of preset buttons → `powercfg /change standby-timeout-ac N` (hidden window); show current via `powercfg /q` parse best-effort (fallback: just buttons).
- [ ] ClipboardMonitor: WM_CLIPBOARDUPDATE → if text & != last, push front of deque (max ClipboardMax); panel lists snippets (trimmed preview), click=copy, pin(saves to settings), delete, clear.
- [ ] Commit per feature.
